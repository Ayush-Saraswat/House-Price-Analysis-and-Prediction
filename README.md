# House Price Exploratory Data Analysis (EDA)

## Overview

- Cleaned and transformed 1,400+ housing records by handling missing values, encoding categorical variables, and
engineering meaningful features for analysis and modelling.
- Conducted exploratory data analysis to identify the top 10 factors influencing house prices through feature importance
analysis and visualizations.
- Applied descriptive statistics, correlation analysis, and visualizations to examine relationships between characteristics
and house prices.
---

## Objectives

- Clean and preprocess the housing dataset.
- Handle missing values and prepare a high-quality analytical dataset.
- Perform descriptive and inferential statistical analysis.
- Explore relationships between housing features and sale prices.
- Identify the top factors influencing house prices using feature importance analysis.
- Generate insights through visualizations and statistical techniques.

---

## Dataset

- **Dataset:** Ames Housing Dataset
- **Target Variable:** `SalePrice`

The dataset contains residential housing information, including:

- Property size and living area
- Construction quality
- Basement and garage details
- Lot dimensions
- Year built
- Exterior characteristics
- Neighborhood information
- Structural and architectural features

---

## Project Workflow

### 1. Data Cleaning

- Removed irrelevant features
- Handled missing values using appropriate imputation techniques
- Treated outliers where necessary
- Encoded categorical variables for analysis
- Created a clean, analysis-ready dataset

---

### 2. Exploratory Data Analysis

Conducted comprehensive EDA using:

- Dataset overview
- Data type inspection
- Missing value analysis
- Descriptive statistics
- Distribution analysis
- Correlation analysis
- Scatter plots
- Histograms
- Boxplots
- Correlation heatmaps
- Pairwise relationship analysis

---

### 3. Statistical Analysis

Applied statistical techniques to better understand the dataset, including:

- Measures of central tendency
- Measures of dispersion
- Skewness and kurtosis
- Pearson correlation analysis
- Feature importance analysis using Random Forest
- Identification of statistically significant relationships between housing features and sale price

---

## Key Insights

- Property quality and overall living area emerged as the strongest drivers of house prices.
- Garage capacity and basement size showed a strong positive relationship with sale price.
- Several structural features exhibited high correlation with property value.
- Correlation analysis highlighted important relationships among housing attributes, providing valuable insights for feature selection.
- Feature importance analysis ranked the top variables contributing to variations in house prices.


---
## Results

The project successfully transformed raw housing data into actionable insights by identifying the characteristics that most strongly influence house prices. Through statistical analysis and visualization, the study provides a clear understanding of feature relationships and establishes a reliable analytical foundation for downstream predictive modelling.
